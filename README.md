# Pokémon Image Loader 🎮

A simple and interactive web application that fetches and displays Pokémon images dynamically using the Pokémon API.

## 🚀 Live Demo

[View Live Demo](https://pokifetch-img-loader.vercel.app/)

## 📌 About the Project

Pokémon Image Loader is a beginner-friendly JavaScript project that demonstrates how to fetch data from an external API and dynamically display it on a webpage.

Users can enter a Pokémon name or use the available controls to load Pokémon images and information.

## ✨ Features

* 🔍 Search for Pokémon
* 🖼️ Dynamically load Pokémon images
* ⚡ Fetch data using an external API
* 📱 Responsive design
* 🎨 Interactive user interface
* ❌ Handles invalid Pokémon names
* 🔄 Updates content without refreshing the page

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Axios / Fetch API
* Pokémon API

## 🌐 API Used

This project uses the [PokéAPI](https://pokeapi.co/) to retrieve Pokémon data and images.

## ⚙️ How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/mani2643/pokemon-image-loader.git
```

2. Navigate into the project folder:

```bash
cd pokemon-img-loader
```

3. Open `index.html` in your browser.

No additional dependencies or installation are required if the project uses CDN/browser-based libraries.
